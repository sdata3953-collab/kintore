# 筋トレ日記（PWA版）

ホーム画面に追加すると、独立したアプリとして全画面で動く。オフラインでも起動する。

## フォルダの中身

- `index.html` … アプリ本体
- `manifest.webmanifest` … アプリ名・アイコンなどの設定
- `sw.js` … オフラインで起動するための仕組み（サービスワーカー）
- `icons/` … アイコン画像

フォルダ構成は変えずに、このままアップロードする。

## 1. GitHub Pages で公開する（無料）

作業はPCのブラウザで行うのが楽である。

1. GitHub のアカウントを作る（すでにあれば不要）
2. 右上の「+」→「New repository」で新しいリポジトリを作る
   - 名前は例えば `kintore`
   - 公開範囲は **Public** にする（無料プランの GitHub Pages は Public のみ）
3. 作ったリポジトリで「Add file」→「Upload files」を開き、このフォルダの中身（`index.html`、`manifest.webmanifest`、`sw.js`、`icons` フォルダ）をドラッグして「Commit changes」
4. リポジトリの「Settings」→ 左メニューの「Pages」を開く
5. 「Build and deployment」の「Source」で **Deploy from a branch** を選び、ブランチは `main`、フォルダは `/ (root)` にして「Save」
6. 1〜2分待つと、Pages の画面に公開URLが表示される
   - 例：`https://ユーザー名.github.io/kintore/`

公開されるのはアプリのコードだけである。トレーニングの記録はそれぞれの端末の中に保存され、GitHub には送られない。

## 2. ホーム画面に追加する

### iPhone

1. 公開URLを **Safari** で開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから開くと、Safari の枠なしの全画面で起動する

### Android

1. 公開URLを Chrome で開く
2. 右上のメニュー →「ホーム画面に追加」（または「アプリをインストール」）

## データについて

- 記録はその端末のアプリ内に保存される
- 機種変更や、claude.ai 版からの移行は「設定」→「バックアップを保存」→ 新しい側で「バックアップから復元」で行う
- iPhone では、ホーム画面のアプリと Safari で開いたページの保存領域は別々である。記録は必ずホーム画面のアイコンから開いて行う

## アプリを更新するとき

- 新しい `index.html` を同じリポジトリにアップロードし直せばよい
- 次にアプリを開いたとき（電波がある場合）に自動で新しい版に切り替わる
