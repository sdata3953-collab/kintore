# 筋トレ日記

iPhone のホーム画面に追加して、独立したアプリとして使える筋トレ記録アプリ（PWA）です。

- 記録はすべて端末内（localStorage）に保存されます。サーバーやアカウントは不要です
- 一度開けば、以後はオフラインでも起動できます（Service Worker でキャッシュ）
- ホーム画面から起動すると、Safari のアドレスバーなしの全画面で動きます

## 公開する（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`（またはこのブランチ）、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/kintore/` で公開されます

## iPhone のホーム画面に追加する

1. iPhone の **Safari** で上の URL を開く
2. 下部の共有ボタン（□↑）→「**ホーム画面に追加**」
3. ホーム画面の「筋トレ日記」アイコンから起動

## 注意

- ホーム画面のアプリと Safari のタブでは保存領域が別です。記録は必ずホーム画面のアイコンから付けてください
- アプリを削除すると記録も消えます。設定画面のバックアップで定期的に書き出しておくと安心です
- アプリを更新したら `sw.js` の `VERSION` を上げてください（次回起動時に新しい版に切り替わります）

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |
| `sw.js` | オフライン用キャッシュ |
| `icons/` | ホーム画面アイコン |
